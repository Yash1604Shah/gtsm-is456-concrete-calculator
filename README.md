# GTSM IS 456 Concrete Cube Acceptance Calculator

Free educational concrete-strength calculator from **GTSM Testing Labs LLP, Ahmedabad**.

## Features

- Enter exactly three individual specimen strengths for each sample, and check the IS 456 Clause 15.4 ±15% variation limit.
- Check general IS 456 Table 11 acceptance limits for groups of **four non-overlapping consecutive valid sample test results**, plus the minimum individual result.
- Explore qualifying small-pour provisions when ≤30 m³ and fewer than four samples are prescribed.
- Try an illustrative M25 set with means 23, 30, 31, 32 MPa and an alternative set containing an individual sample result of 21 MPa.
- Contact GTSM for actual construction-material testing and laboratory quotations.

## Technical scope

This is **not** an accredited laboratory report, structural clearance or complete code-compliance check. The user is responsible for confirming actual sampling frequency, specimen and sample traceability, concrete quantity, correct IS 456 amendment, IS 516 testing procedures, applicable standard deviation, quality records and contract requirements. Invalid sample results must be investigated and must not be used for acceptance conclusions.

Reference: **IS 456:2000**, Clause 15.4, Table 8 and Table 11 **as amended**. Consult current official BIS standards.
